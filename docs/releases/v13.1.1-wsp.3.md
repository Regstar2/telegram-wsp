# Telegram-WSP v13.1.1-wsp.3

**Русский** · [English](v13.1.1-wsp.3_EN.md)

## О релизе

Совместимое обновление Telegram-WSP 13.1.1 (Telegram build 7237), ревизия WSP 3. Основная цель — обновление встроенного TgWsProxy runtime до исправлений маршрутизации из Android-форка. Это не обновление Telegram upstream и не отдельное приложение TgWsProxy.

## Главное

- Обработка полного истощения Cloudflare Proxy domain pool без лавины одинаковых диагностических сообщений.
- Отмена устаревших CF dial/TLS-попыток после остановки прокси или смены маршрута.
- Совместимость WebSocket/TLS и корректная обработка Worker transport/failover.

## Изменения

### Исправлено

- CF Proxy: учёт cooldown/in-flight/reservation по DC, классификация исчерпанного пула и ограниченная телеметрия повторных отказов.
- MTProto: привязка событий к поколению route policy; старые события не должны ошибочно выглядеть как fallback нового маршрута.
- CF/WebSocket: обработка отмены соединения и TLS-handshake; согласование причин ошибок.
- Worker: обновлены TLS и транспортные пути, диагностика соединения и переключение резервных узлов.

### Изменено

- Обновлён reusable `tgwsproxy-core`; собственный порядок Auto-маршрутов Telegram-WSP, AWG и запрет неразрешённого fallback сохранены.
- Версия Telegram upstream и Android package ID остаются `13.1.1` и `org.telegram.messenger.web`.

## Установка и обновление

Загрузите опубликованный `Telegram-WSP-release.apk` из [GitHub Releases](https://github.com/Regstar2/telegram-wsp/releases/tag/v13.1.1-wsp.3). Для обновления с WSP 2 используйте системный установщик поверх существующей копии с тем же сертификатом; удаление данных не требуется при совпадении подписи. Встроенная проверка обновлений использует `latest.json`; окончательное разрешение на установку даёт пользователь. Требуется совместимая версия Android (смотрите `minimumSdk` в `latest.json`).

## Проверено

Репозиторий использует проверки `tgwsproxy-core` (Go, Android unit tests, AAR), Telegram-WSP integration CI и signed release pipeline. Фактические результаты конкретной сборки опубликованы в [GitHub Actions](https://github.com/Regstar2/telegram-wsp/actions) и [CI ядра](https://github.com/Regstar2/tgwsproxy-core/actions). Наличие описания не означает, что физические сетевые маршруты были проверены на пользовательском устройстве.

## Известные проблемы

Доступность CF Proxy, Worker и WARP зависит от сети и доступных endpoint; это обновление не гарантирует обход внешних блокировок. Работа маршрутов в реальных сетях требует отдельного приёмочного теста, который не заменяется компиляцией.

## Артефакты

- `Telegram-WSP-release.apk` — подписанный Android APK.
- `latest.json` — метаданные обновления, версия и SHA-256 APK.
- `SHA256SUMS.txt` — контрольные суммы.
- `SOURCE_MANIFEST.json` и архивы Corresponding Source — точные исходные компоненты.

Размеры и SHA-256 следует брать из фактических опубликованных assets, не из этого описания.
